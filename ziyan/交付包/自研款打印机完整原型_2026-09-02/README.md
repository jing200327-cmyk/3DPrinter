# 自研款打印机完整离线原型

本目录包含“自研款打印机打印旅程原型”和“自研款打印机打印页面原型”，以及页面所需的全部本地图片素材。

## 查看方式

1. 完整解压压缩包，不要只在压缩软件预览窗口中打开文件。
2. 双击根目录的 `打开完整原型.html`。
3. 推荐从“开始完整打印旅程”进入，按页面按钮体验选盘、配色、准备中、打印中、队列和完成流程。
4. 推荐使用最新版 Chrome 或 Edge，浏览器缩放设为 100%。

无需安装依赖、无需联网、无需启动本地服务器。

## 直接入口

- 打印旅程：`dayinlvchengv2/打印旅程原型/index.html`
- 打印页面：`dayinji/自研款打印机打印页面原型/index.html`

## 目录说明

- `dayinlvchengv2/`：自研款打印机打印旅程 v2 原型
- `dayinji/`：自研款打印机打印页面原型
- `src/dayinji/`：两个原型依赖的打印机图片素材
- `ugee/Ugee打印机页面原型/assets/`：打印页面复用的设备页底图

请保留目录结构不变，否则跨页面跳转或图片相对路径可能失效。
