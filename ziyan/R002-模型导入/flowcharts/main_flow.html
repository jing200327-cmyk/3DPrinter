2 主线 A · 本地导入（理想路径） 选择文件 → 逐文件校验 → 超限压缩 → 批量上限 → 导入中 → 自动分盘 → 编辑页 → 接 R001
选择本地文件
拉起手机系统文件目录，支持多选 + 已选计数 + 全选；模拟页演示，正式产品调系统选择器
单次 ≤ 20 个 · ≤ 300MB
逐文件校验
固定顺序：格式白名单 → 单文件体积 ≤ 100MB → 三角面 ≤ 100 万。体积小但面数超限的文件同样被拦
校验顺序错了功能等于不存在
超限压缩
体积超限先给选择：按类型自动压缩（3mf 减面 / stl·obj 公差 / gcode 精度 / stp 弦高）或取消重选
压缩后仍超限 → 拒绝
批量上限
超出 20 个 / 300MB 的文件不导入；校验通过的照常进入队列
丢弃并明确提示
导入中
进度条 + 当前文件名 + i / N，导入过程可见、可感知
传输失败可重试
自动分盘
通过的文件自动分盘（追加新盘）+ 自动布局；每盘以来源文件名独立命名
最多 8 盘
编辑页 · 多盘态

全部成功仅 Toast 提示

4 异常与边界 所有失败都给具体原因与下一步动作，绝不静默
格式不支持
白名单外（stl / 3mf / obj / gcode / stp / zip 之外）记入失败清单，结果弹窗逐条列出
压缩后仍超限
「文件过大，无法继续导入」，提示导出精简版本后重试
批量超限
超出 20 个 / 300MB 的部分不导入，明确提示丢弃数量
8 盘上限
触达上限后剩余文件直接丢弃并提示「已达 8 盘上限」，不合并、不生成第 9 盘
部分成功
通过的文件正常导入，失败不阻断、不整体回滚；失败项在前逐条列原因
上传失败
保留已选文件清单，「重试未导入项」自动回填勾选，无需重新找文件
绑定拦截
未绑定 / 凭证失效 / 未登录 → 禁止进入传输页，明确原因 + 下一步（去绑定需联网）
凭证超期
> 30 天未联网校验：允许继续 + 强提示，不做硬拦截
