# 自研款打印机打印页面 HTML 原型

双击 `index.html` 即可离线预览，无需安装依赖或启动服务。

## iPhone 13 mini 设备框

整个原型按 **iPhone 13 mini 的 375 × 812 逻辑像素**排版，所有页面（主页、参考图页、复用大图页、进料中/退料中、风扇提醒弹窗、逻辑演示页）都锁在同一个设备框里：

- `--device-width: 375px` / `--device-height: 812px`；`--frame-height: min(100vh, 812px)`、`--frame-top: max(0px, (100vh - --frame-height) / 2)`。窗口比 812 高时设备框垂直居中、上下留白，窗口比 812 矮时设备框铺满视口，不留留白。
- 原来按 390 宽设计时写死的 px 偏移（顶栏切换按钮、设置入口、顶栏裁切高度、状态小图位置、底部导航裁切高度等）统一乘 `--u: calc(var(--device-width) / 390)` 换算到 375，热区不会偏。
- **页面过长时在设备框内部上下滚动**：`.phone-shell` 等层改成 `overflow-x: hidden; overflow-y: auto` + 固定 812 高，主页面在 375 × 812 下可滚 136px。比 375 还窄的视口（≤359px）会退化成 `--device-width: 100vw`，整页按视口宽度等比缩放。
- 原生滚动条会占掉 6~15px 布局宽度，把按宽度等比排版的整图复用页压出底部空白，所以设备框内的滚动条一律隐藏，改用一条**不占宽度的浮层滚动指示条**（`#scroll-indicator`，4px，贴在设备框右侧内缘，和 iOS 一样只在滚动时浮现、进页面时多停 2.2 秒让人看得见）。内容超出 4px 才出现，避免整图页 1~2px 的微溢出乱弹。
- 桌面端打开时看到的就是一台居中的 375 × 812 手机；在真机 iPhone 13 mini 上 `min(100vw, 375px)` 与 `min(100vh, 812px)` 正好等于全屏，两者视觉一致。

## 发布（线上预览）

**固定发布地址（2026-10-20 用户指定）**：[准备打印原型](https://jing200327-cmyk.github.io/3DPrinter/dayinji/自研款打印机打印页面原型/index.html)。每次修改并验收后，将构建产物发布到同仓库 `gh-pages`，保持域名和路径不变，部署完成后回读原地址并验证。发布 checkout 为 `E:\3Dprinter\pages\printer-prototypes`，完整流程见 `../../_memory/GITHUB_PAGES.md`。此约定取代此前 Sites / WorkBuddy 默认发布选择；旧站点保留。

两套原型用 `../../` 相对路径互跳，必须同站点发布；发布目录由 `lianjiepeiwnag/打印机首次配网连接流程原型/tests/build-publish.py` 生成（默认 `ziyan/_publish-prototypes`，也可传参指定新目录，例如 `ziyan/_publish-prototypes-r008`），互通校验用 `tests/publish-links-check.mjs <站点根URL>`。发布根页（启动器）会列出两个原型的入口，含「打印机离线状态」工作台直达链接。

**静态资源一律带 `?v=` 版本查询串**（`styles*.css` / `share-code-pool.js` / `prototype.js`）。原因：线上网关会按 `Accept-Encoding` 分片缓存静态文件，重新部署后浏览器仍可能命中旧分片（表现为新 HTML 配旧 JS → 页面报 `Cannot read properties of null`）。**以后每次改动这些文件，都要把 `index.html` 里的 `?v=` 值往上抬一版**（`styles.css` 与 `prototype.js` 当前 `r012`，其余仍 `r008`），并在契约测试里被强制校验。

> `?v=` 只需抬高**被改动的那几个文件**。例如只改了 `styles.css`，就只把 `styles.css?v=` 抬一版（`index.html` 与 `index-offline.html` 两处都要改），其它文件保持不动。

> **注意：网关连 `index.html` 本身也可能缓存**。出现旧内容时，检查原站点的部署是否更新、入口 HTML 与静态资源版本是否一致，并在原发布平台刷新缓存。按用户固定链接约定，不再通过更换沙箱或域名规避缓存。发布后须回读原地址的 HTML、JS，并验证 UG-01 绑定拦截与 UG-02 连接交互。
