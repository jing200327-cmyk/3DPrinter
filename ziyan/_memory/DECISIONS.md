## C · R002 模型导入

### DEC-027 导入限制采用「三层闸门」而非单一文件体积
- **决定**：能否导入的判定为**双条件**——① 单文件 ≤ **100MB**；② 模型三角面 ≤ **100 万面**（压缩后再判定）。批量另设 ③ 单次最多 **20 个文件**、总量 ≤ **300MB**。触达 ②/③ 统一提示「模型过于复杂，建议导出精简版本后重试」。
- **理由**：用户确认「大小数量限制按表」。体积小但面数极高的文件会绕过体积闸门，导致云切片必挂；纯按体积限制会留下"能导入但必失败"的体验黑洞。
- **⭐ 待实测校准**：100 万面 / 20 个 / 300MB 三个数值为 AI 拟定（用户已确认采用），需在云切片实测后回填真实阈值。
- **来源**：R002 步骤一第 1 轮「决策 A」（用户确认）
- **影响范围**：R002 §2 校验规则、BR-021、原型校验弹窗文案
- **文档锚点**：飞书 2.2.3 需求功能清单 / 2.2.7 格式与大小校验 + 自动压缩（M6）

### DEC-028 无网打印的绑定判定走「本地凭证 + 双向握手」
- **决定**：无网（无公网）时，APP 与打印机经**局域网本地**通信完成鉴权，不依赖云端。
  - 配网绑定成功时，APP 将 `设备ID + 本地密钥/证书` 写入本地安全存储，形成**已绑定设备列表**。
  - 连上打印机热点后自动握手：**APP 侧**校验设备ID 是否在本地列表；**设备侧**校验 APP 凭证。
  - **两端都通过** → 允许进入文件传输页上传 gcode。
  - 未绑定 / 无该设备 → **禁止进入传输页**，提示「该打印机尚未与当前账号绑定」+「去绑定」引导（需联网）。
  - 设备侧拒绝（已解绑/已绑他号）→ **禁止**，提示「打印机绑定信息已失效，请联网后重新绑定」。
  - APP 未登录 → **禁止**，提示「请先登录后再进行无网打印」。
  - 本地凭证超 **30 天**未联网校验 → **允许但强提示**「建议联网校验绑定状态」（离线可用是刚需，不硬拦）。
- **理由**：用户确认「无网绑定机制按表」+「未绑定禁止进入传输页」。只查 APP 本地列表会被"设备已解绑/换机"绕过；只查设备侧无法确认"是不是当前账号的"，故必须双向。
- **来源**：R002 步骤一第 1 轮「决策 B」（用户确认）
- **影响范围**：R002 §5 无网导入、BR-057（原 BR-023）、原型无网链路
- **文档锚点**：飞书 2.2.3 需求功能清单 / 2.2.9 无网环境导入（M9）（需导入前连接打印机热点）

## DEC-075 无网打印技术方案 = 手机连接打印机热点，局域网内直传 gcode

- **决策**：无网打印的**技术方案**为「**手机连接打印机热点 → 通过热点连接 → 手机向打印机传输 gcode 文件 → 打印机执行打印**」，全程不依赖公网。
- **配套决策**：两个无网入口**不直接进入手机系统文件目录**，改为先进**无网热点引导页**（两步图文：① 长按打印机红色重置键 ② 点击底部「去打印」）；点「去打印」后 APP **自动连接打印机热点**，**连接建立后**才跳转文件目录。
- **按钮规格**：底部「去打印」**圆角 30px**、**从左至右紫色 → 蓝色渐变**。
- **理由**：无热点连接时，用户在文件目录里选中的 gcode 根本无法传输，用户会以为功能坏了；把「连热点」这一步显性化并由 APP 自动完成，可同时降低操作门槛与失败率。（用户确认 2026-10-15）
- **被否方案**：① 两入口继续直达文件目录、连接热点放在传输页失败后再提示；② 让用户自己去系统设置手动连打印机 WiFi。
