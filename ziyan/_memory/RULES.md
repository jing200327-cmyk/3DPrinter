## A · R001 模型编辑与切片（编辑 / 参数 / 打印盘）

### BR-001 打印参数 5 层读取优先级
- **规则**：① 当前任务用户手动修改值 → ② 当前模型已保存参数 → ③ 用户默认打印参数 → ④ 系统默认参数 → ⑤ 算法自动推荐参数。
- **关联**：GL-020 参数优先级
- **来源**：R001（用户确认，§23）
- **文档锚点**：飞书 2.1.10 打印设置与参数优先级（M11、M12） / 2.1.3 需求功能清单 / 2.2.13 附件

### BR-002 支撑参数的特殊优先级
- **规则**：支撑参数若用户**未手动保存或修改**，允许算法根据当前模型**重新推荐**；不得被固定的"默认开启"永久覆盖。
- **关联**：GL-012 支撑、BR-001
- **来源**：R001（用户确认，§23）
- **文档锚点**：飞书 2.1.10 打印设置与参数优先级（M11、M12） / 2.1.3 需求功能清单

### BR-003 打印参数默认作用于整个打印任务
- **规则**：打印模式、底座、喷嘴温度、填充密度对**所有打印盘**生效；用户手动指定的支撑开关/类型默认作为**整个任务统一策略**。本期**不支持**每盘独立打印参数。
- **关联**：BR-002、§24
- **来源**：R001（用户确认，§24）
- **文档锚点**：飞书 2.1.10 打印设置与参数优先级（M11、M12） / 2.1.3 需求功能清单

### BR-004 复制失败不新建打印盘
- **规则**：复制时若当前盘找不到合法位置，**不自动创建新盘**，复制失败并提示"当前打印盘空间不足，无法复制"。
- **理由**：避免用户无感知地增加打印盘数量。
- **来源**：R001（用户确认，§8）
- **文档锚点**：飞书 2.1.3 需求功能清单 / 2.1.6 模型编辑操作：缩放、复制、删除（M4、M5、M6）

### BR-005 删除后空盘自动回收与盘号前移
- **规则**：删除后当前盘无任何零件、**且任务内其他盘仍有零件**时，**自动删除该空盘**，后续盘号依次前移并重新编号，页面切换至距离当前盘最近的有效打印盘。
- **⛔ 例外条款已作废（2026-09-28 修订）**：原"若删除的是整个项目最后一个模型则保留空打印盘"**不再适用**，改为见 **BR-019**（二次确认 + 任务自动移除）。
- **来源**：R001（用户确认，§9；修订见 DEC-022）
- **文档锚点**：飞书 2.1.3 需求功能清单 / 2.1.6 模型编辑操作：缩放、复制、删除（M4、M5、M6）

### BR-006 未选中零件时三个编辑按钮不置灰
- **规则**：未选择零件时，「缩放」「复制」「删除」保持**正常视觉状态（不置灰）**，点击不执行操作并 Toast 提示"请先选择一个模型"。
- **关联**：GL-002 模型
- **来源**：R001（用户确认，§5）
- **文档锚点**：飞书 2.1.3 需求功能清单 / 2.1.5 3D 视图区与编辑工具栏（M2、M3）

### BR-007 越界与可打印性判定
- **规则**：零件任何部分超出 180×180×180 mm → 红色异常态 + 该盘标记为异常盘；多盘模型中**任意一盘异常 → 整个打印任务不可打印**。
- **来源**：R001（用户确认，§11）
- **文档锚点**：飞书 2.1.3 需求功能清单 / 2.1.8 越界与可打印性校验（M8）

### BR-008 「去打印」可点击的完整条件
- **规则**：需**同时**满足 ① 至少存在一个模型 ② 所有打印盘均存在有效零件 ③ 所有零件位于可打印范围内 ④ 不存在模型碰撞等阻断问题 ⑤ 云端切片服务可用。任一不满足 → 按钮置灰，并在按钮附近显示阻断原因。
- **关联**：BR-007、GL-013 去打印
- **来源**：R001（用户确认，§11.3）
- **文档锚点**：飞书 2.1.12 异常与边界处理 / 2.1.3 需求功能清单 / 2.1.8 越界与可打印性校验（M8） / 2.2.3 需求功能清单 / 2.2.4 入口与导入选择弹窗（M1、M2）

### BR-009 分盘上限与编号规则
- **规则**：盘号从 **1** 起连续排列，**最大支持 8 个打印盘**，默认选中第 1 盘；宽度不足时盘号区支持横向滑动。单盘模型不展示盘号切换控件。
- **关联**：GL-001 打印盘
- **来源**：R001（用户确认，§3.2）
- **文档锚点**：飞书 2.1.3 需求功能清单 / 2.1.4 页面结构与导航、模型名称与分盘切换（M1） / 2.1.7 自动摆盘与智能优化（M7、M16） / 2.2.3 需求功能清单 / 2.2.8 导入执行、自动分盘与结果反馈（M7、M8）

### BR-010 视角操作与模型操作严格分离
- **规则**：单指拖动仅旋转**观察视角**，双指捏合仅改变**相机视角**，两者都**不改变模型的姿态、摆放方向与实际尺寸**。"双指缩放视图"与工具栏"模型缩放"是不同能力，不可混淆。
- **来源**：R001（用户确认，§4.3）
- **文档锚点**：飞书 2.1.3 需求功能清单 / 2.1.5 3D 视图区与编辑工具栏（M2、M3）

### BR-011 参数修改即时生效，保存决定持久化
- **规则**：参数修改 = 当前任务立即生效；「保存」只决定是否持久化（存为模型级或全局偏好），**不承担"确认生效"职责**。
- **来源**：R001（用户确认，§13.1）
- **文档锚点**：飞书 2.1.3 需求功能清单

### BR-012 缩放取值范围
- **规则**：百分比模式范围 **10%–300%**，默认 **100%**；尺寸模式仅接受有效正数，非法字符或 0、负数不生效。具体尺寸上限不写死 180mm，以模型实际包围盒与打印空间碰撞检测结果为准。
- **关联**：GL-015 尺寸模式/百分比模式
- **来源**：R001（用户确认，§7.3–§7.4）
- **文档锚点**：飞书 2.1.3 需求功能清单 / 2.1.6 模型编辑操作：缩放、复制、删除（M4、M5、M6）

### BR-013 「应用至所有盘的零件」的作用范围
- **规则**：
  - **默认关闭**。关闭时缩放（含重置）**只作用于当前选中的那一个零件**；同盘其他零件、其他打印盘都不受影响。
  - **开启后**，缩放按**相同比例**同步到**全部打印盘上的零件**；尺寸模式以比例同步，而非强制所有零件使用相同绝对 XYZ 尺寸。
  - 删除、复制**始终只作用于选中的那一个零件**。
- **展示**：**单盘与多盘均展示**（2026-09-29 修订，见 DEC-023）；单盘开启后即为该盘全部零件
- **关联**：GL-024 应用至所有盘的零件（原 GL-017）
- **来源**：R001（用户确认，§7.6 + 评审第 2 轮纠正 DEC-021）
- **文档锚点**：飞书 2.1.3 需求功能清单 / 2.1.6 模型编辑操作：缩放、复制、删除（M4、M5、M6）

### BR-014 自动摆盘触发时机与目标
- **规则**：缩放结束、复制、删除后自动执行；仅作用于**当前打印盘**。目标：① 全部模型位于打印空间内 ② 模型间不碰撞 ③ 保留必要间距 ④ 提高空间利用率 ⑤ 尽量减少不必要的位置变化。摆盘失败时保留编辑结果并标识异常、禁用「去打印」。
- **关联**：GL-006 自动摆盘
- **来源**：R001（用户确认，§10）
- **文档锚点**：飞书 2.1.3 需求功能清单 / 2.1.7 自动摆盘与智能优化（M7、M16）

### BR-015 状态保存（后台恢复）
- **规则**：缩放/复制/删除/参数修改实时保存至当前编辑任务；APP 因锁屏、切换应用等进入后台后返回，至少恢复：当前打印盘、各盘模型、模型尺寸、模型位置、打印参数。

### BR-016 本期不增加退出二次确认
- **规则**：模型编辑页「返回」**不做**退出确认弹窗；当前页面发生过编辑或参数修改时**默认保留**编辑结果。
- **来源**：R001（用户确认，§2.2）

### BR-017 复位与恢复默认值的范围
- **规则**：
  - 缩放面板「重置」→ 当前模型恢复至**进入编辑页面时**的原始尺寸（100%），等比例状态不改变；「应用至所有盘」开启时同步重置所有盘。

### BR-020 保存切片（准备打印页）
- **触发**：准备打印页底部左侧「保存」。
- **规则**：
  - 弹出**命名弹窗**，输入框默认填入**当前模型名称**，支持用户自定义（≤ 40 字）。
  - **名称为空时「确定」置灰**并提示「名称不能为空」；「取消」返回准备打印页、不进入保存。

  - 保存完成后弹出**保存成功弹窗**：名称回显 +「可以在「我的 - 我的切片」中查看。」+「立即查看」。
  - 「立即查看」跳「我的 - 我的切片」（**该页本期不实现**）；「完成」关闭弹窗并停留在准备打印页。

## B · R002 模型导入（校验 / 弹窗 / 分盘 / 无网）

### BR-021 导入文件格式与三层限制【2026-10-09 精化】
- **规则**：
  - **格式白名单**：`stl`、`3mf`、`obj`、`gcode`、`stp/step`、`zip`（6 类）。不在列表内 → 「当前文件格式不支持」。
  - **格式校验**：同时校验**文件扩展名**和**文件实际内容**，防止扩展名与实际格式不一致（不一致 → 「文件格式异常，无法识别」）。
  - **文件类型区分**：
    - 模型文件（stl / 3mf / obj / stp）：支持模型解析、预览及符合条件的自动优化。
    - 打印指令文件（gcode）：**不参与三角面数量校验及有损压缩**，导入后进行打印机兼容性校验。
    - 压缩包文件（zip）：解压后对内部文件逐个执行格式、大小及复杂度校验。
  - **三层闸门**：
    | 层 | 限制 | 判定时机 |
    | :-: | --- | --- |
    | ① | 单文件 ≤ 100MB | 选择文件后立即校验；允许优化的文件在优化后重新校验 |
    | ② | 单模型三角面 ≤ 100 万面 | 模型解析后校验；超过限制则尝试简化并重新校验 |
    | ③ | 单次 ≤ 20 个有效文件，且总量 ≤ 300MB | 所有文件完成校验及优化后、写入打印盘前 |
  - **数值定义**：文件大小统一使用**十进制 MB（1MB = 1,000,000 Bytes）**；100MB 为单文件导入体积限制（非打印机最大切片能力）；100 万面为模型解析后用于预览/编辑的**单模型工作网格上限**；20 个指单次导入的**有效文件数量**（ZIP 按解压后统计，一个 3MF 仍计一个文件）；300MB 按**完成必要转换及优化后**的有效导入文件大小总和计算。上述数值为初始业务阈值，需通过目标手机及打印机上位机性能测试验证。
  - **校验顺序（实现约定）**：文件选择 → 格式及安全校验 → 单文件体积校验 → 文件解析 → 三角面校验 → 必要的自动优化 → 优化结果复核 → 批量数量及总量校验 → 导入打印盘。
  - ⚠️ **顺序要求**：不得在单文件自动优化前执行 300MB 总量拦截；文件解析过程须设置独立的内存和资源保护限制。
- **关联**：BR-022 自动优化、BR-023 超限交互、BR-024 压缩结果校验、BR-025 ZIP、BR-026 批量、GL-029、DEC-027、DEC-066
- **来源**：R002（用户提供完整规则文本，2026-10-09；DEC-066）
- **文档锚点**：飞书 2.2.3 需求功能清单 / 2.2.7 格式与大小校验 + 自动压缩（M6）

### BR-022 自动压缩 / 优化策略【2026-10-09 精化】
- **触发条件**：① 单文件超过 100MB 且文件类型支持优化；② 模型解析后三角面超过 100 万面；③ 用户主动选择优化模型（可选功能，V1 可暂不支持）。
- **优化原则**：
  - 优先采用**无损转换或无损压缩**；无损无法满足限制时，**在用户确认后**执行有损网格简化。
  - 有损优化必须控制**几何偏差**，不得仅以文件体积达标作为成功条件。
  - 不得默认删除影响打印结果的必要数据（颜色、材料映射、模型结构）。
  - **原始文件不覆盖**，优化结果生成独立工作文件。
- **按类型策略**：

  | 文件类型 | 自动压缩/优化策略 | 关键参数 | 处理说明 |
  |---|---|---|---|
  | stl | ASCII 优先转 Binary STL；必要时网格简化 | 几何偏差建议 ≤0.05mm；目标 ≤100 万面 | 二进制转换为无损；网格简化为有损 |
  | obj | 网格简化，优化冗余几何数据 | 同上 | 默认保留材质及纹理引用；确需移除须用户确认 |
  | 3mf | 优先无损重打包；仍超限再网格简化 | 同上 | 保留必要的颜色、材质及对象关系 |
  | gcode | 不执行有损压缩；仅支持经兼容性验证的无损压缩或编码 | 不修改坐标精度、挤出量及运动指令 | 不适用三角面校验；超限且无法无损处理则导入失败 |
  | stp/step | CAD 曲面离散化为三角网格 | 默认弦高公差 0.05mm；必要时 0.10mm | 转换后校验体积、面数和几何偏差；不直接修改原始 STEP |
  | zip | 安全解压后对内部文件分别执行对应格式策略 | 解压总量建议 ≤300MB；有效文件 ≤20 个 | ZIP 本身不执行几何简化，需校验内部文件及解压资源消耗 |

  > ⚠️ 0.05mm / 0.10mm 为 V1 建议的初始工程参数，并非行业统一标准，应结合打印精度、模型细节及目标设备性能测试确定。
- **网格简化约束**：简化后 ≤100 万面；默认最大几何偏差建议 ≤0.05mm；尽可能保留模型边界、孔洞、薄壁及连接结构；模型体积变化率建议 ≤1%（异常检测辅助指标，非唯一成功条件）；无法在允许几何偏差内满足要求 → 优化失败；**不得通过无限增加几何公差强制压缩成功**。
- **关联**：BR-021、BR-023、BR-024、DEC-066
- **来源**：R002（用户提供完整规则文本，2026-10-09；DEC-066）
- **文档锚点**：飞书 2.2.3 需求功能清单 / 2.2.7 格式与大小校验 + 自动压缩（M6）

### BR-023 超限交互【2026-10-09 新增】
- **规则**：
  - **单文件超过 100MB**：支持自动优化 → 弹确认弹窗：标题「文件超过100MB」，内容「当前文件：（文件名+大小）。可尝试自动优化后导入，优化可能导致模型部分细节发生变化。」，展示优化策略，按钮「取消 / 自动优化」；不支持自动优化 → 提示「文件过大，暂不支持自动优化，请重新选择模型。」

### BR-024 压缩结果校验【2026-10-09 新增】

### BR-025 ZIP 文件处理规则【2026-10-09 新增】
- **规则**：
  - ZIP 作为**文件容器**处理，不直接作为模型对象导入；解压后仅允许包含白名单内可处理的有效文件，按实际文件数量及体积执行校验。

### BR-026 批量导入及异常处理【2026-10-09 新增】
- **批量校验**：所有文件完成独立校验及优化后统计有效文件数量和总大小；≤20 个且 ≤300MB 允许继续导入。**超出时不自动删除文件或擅自选择导入部分文件**——展示超限原因，允许用户返回文件列表移除后重试。

  | 格式不支持 | 跳过当前文件 | 当前文件格式不支持 |

  | 优化后仍超过 100MB | 当前文件标记失败 | 文件过大，无法继续导入 |
  | 优化后仍超过 100 万面 | 当前文件标记失败 | 模型结构过于复杂，无法继续导入 |
  | 优化导致几何偏差超限 | 当前文件标记失败 | 模型优化可能影响打印效果，无法继续导入 |
  | 模型解析失败 | 当前文件标记失败 | 模型文件异常，无法解析 |

### BR-062 自动摆盘智能优化
- **触发**：模型包含**多个模型文件**时，用户进入模型编辑页（由模型详情页「打印设置」或导入完成进入）时由系统自动执行；用户无需手动触发。
- **规则**：
  - 在**不超过打印空间范围**（180 × 180 × 180 mm）的前提下，**同色模型文件自动摆置同一打印盘**。

### BR-063 多选导入的文件类型组合限制（模型文件不可与 gcode / zip 混入）【2026-10-14 新增】
- **规则**：
  - **模型文件**（stl / 3mf / obj / stp/step）：**支持多选**上传，多文件自动分盘（BR-031）。
  - **打印指令文件 gcode** 与 **压缩包文件 zip**：**只能单独上传**，不与其他任何文件一起导入。
  - **混合场景**（命中即拦截）：多选时出现任一 gcode 或 zip，包括「模型 + gcode」「模型 + zip」「gcode + zip」「多个 gcode」「多个 zip」。
- **判定时机**：点「导入」后的**格式及安全校验阶段首先执行**（先于扩展名 / 实际内容校验），命中即**阻止本次导入，不进入上传步骤**。
- **拦截弹窗**：标题「无法一起导入」；内容「模型文件与gcode切片文件和zip压缩包不可一起导入」；辅助说明「模型文件（stl / 3mf / obj / stp）可多选导入；gcode 与 zip 需单独导入」；单一主按钮「**确定**」。
- **点「确定」→ 返回手机本地文件页**，已选文件保留（用户可移除后重试，与 BR-026 批量超限口径一致）。
- **目录侧引导**：gcode / zip 条目带「仅可单独导入」标签；混合勾选时底部实时提示「模型文件不可与 gcode / zip 一起导入」。
- **单独上传 gcode 的落点**：导入完成后自动跳转**切片预览页**（只读），不写入编辑页打印盘（见 DEC-074）。

## BR-064 无网热点引导页（两个入口不再直达文件目录）

- **规则**：无网环境的两个入口（顶部网络提醒条上的「无网打印 >」、自动弹窗「去无网打印」）点击后，**均先进入「无网热点引导页」，不直接进入手机系统文件目录**。
- **引导页内容**：图文并茂的**两步指引**——
  - 步骤① **长按红色重置键**：在打印机通电状态下长按机身上的红色重置键约 3 秒；页面把「红色重置键」以红色高亮块标出。
  - 步骤② **点击底部「去打印」**：APP 会自动连接打印机热点，连接建立后自动打开文件目录。
- **图示**：当前以**占位符**表示（虚线框 + 「占位图 · xxx」标注），设计稿交付后替换为真实插画 / 截图。
- **底部「去打印」按钮**：整宽主按钮，**圆角 30px**，**从左至右紫色 → 蓝色渐变**（`#7B5CFF → #3E8BFF`，90deg），与切片预览页打印按钮视觉一致；双行结构（主文案「去打印」+ 副文案「自动连接打印机热点」）。
- **连接流程**：点「去打印」→ APP **自动发起打印机热点连接** → 显示加载态（「正在连接打印机热点…」+「请确保打印机已开机并处于热点状态」）→ **连接建立后**才跳转手机系统文件目录（无网模式，仅 gcode，确认按钮 =「打印」）。
- **返回规则**：引导页顶部 `‹` → 返回**进入引导页之前所在的页面**（从哪来回哪去）；文件目录 `‹` → 回到**热点引导页**（而非来源页）。
- **提醒条的显示范围（v1.1.5）**：常驻网络提醒条只在**链路外的页面**（工作台 / 创意空间 / 编辑页等）展示；进入**热点引导页**与**无网文件目录**后**不再叠提醒条**——这两页已自解释，叠层属重复提示。离开链路回到来源页后提醒条恢复。（准备打印页沿用既有例外：用自己的顶部无网标签，同样不叠提醒条）
- **引导页不设底部提示**：不展示「连接热点期间手机会暂时断开公网…」这类说明（v1.1.5 删除）。
- **异常——热点连接失败 / 超时（v1.1.6）**：
  | 项 | 内容 |
  |---|---|
  | 触发 | 点「去打印」后 APP 发起热点连接，连接失败或超时（超时阈值 AI拟定·待确认，建议 10s） |
  | 落点 | **保留在引导页**，**不跳转**手机系统文件目录 |
  | 提示形态 | 加载圈切换为**红色警示图标**，主文案「**未能连接到打印机热点**」，辅助说明「请确认打印机已开机并处于热点状态，然后重试。」 |
  | 出路 | 弹盒内**整宽「重试」按钮**（圆角 22px，紫→蓝渐变）；点击重新发起连接，回到「正在连接打印机热点…」加载态 |
  | 再次失败 | 回到本失败态，可**无限重试**（不设次数上限） |
- **加载态视觉**：连接中弹盒内为**居中加载圈** +「正在连接打印机热点…」+「请确保打印机已开机并处于热点状态」。加载圈是块级元素，须用 `margin: 0 auto` 居中（`text-align:center` 对块级无效）。
