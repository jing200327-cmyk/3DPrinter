# 用户旅程 (User Journeys)

> ID 前缀 `UJ-`｜跨需求复用，新需求若落在既有旅程中应扩展而非另起

### UJ-001 选模型 → 编辑 → 切片 → 准备打印（R001 主旅程；2026-09-29 由 R002 扩展首尾）
- **阶段**：① **【R002 新增】获取模型 → 导入** → ② 进入编辑 → ③ 编辑模型 → ④ 调整参数 → ⑤ 提交切片 → ⑥ 确认准备打印 → ⑦ **【R002 新增】保存切片 → 复用**
- **关键触点**：
  `创意空间「导入模型」`（`#creative-space`）→ `#import-sheet 导入选择弹窗` →（我的 AI 创作 / 我的切片 / **导入本地模型** `#system-picker`）→ `#model-editor` →（R001）「更多」`#print-settings` →（去打印）`#slicing-loading` → `#prepare-print` →（保存）`#save-done-dialog` → **「我的切片」**（`#import-sheet/slice`，回到 R002 的读取源）
- **已知痛点**（AI推断·待确认）：现有链路只有"选盘→选耗材→打印"，**缺少对模型的编辑与参数控制能力**；且**用户自己的模型（网盘/聊天软件/建模工具导出）进不到 APP 里**，只能打模型库已有的。已切片成果保存后也没有查看入口。
- **产品机会点**：
  1. 把"切片"从黑盒变成可控环节——可视化 3D 预览 + 参数可见可调 + 自动摆盘与支撑推荐降低门槛。
  2. **补上创作链路的起点（R002）**：导入让"用户自己的模型"能进来，多选 + 自动分盘让"一次多打"成为默认行为。
  3. **让已切片成果可复用（R002）**：准备打印页「保存」→「我的切片」→ 下次直接选用，闭环成立。
- **来源**：R001（步骤一）；前置段与闭环段由 **R002** 扩展

### UJ-002 无网环境打印（R002 新增）
- **阶段**：① 感知网络异常 → ② 选择出路 → ③ 连接打印机热点 → ④ 绑定门禁 → ⑤ 局域网传输 → ⑥ 进入编辑页
- **关键触点**：
  `#netBanner 网络提醒条（常驻）` +「无网打印 >」｜`#offline-dialog 自动弹窗（每登录会话一次）` → `#offline-picker 手机文件目录（仅 gcode）` → 打印机热点 → `#offline-unbound / #offline-invalid / #offline-guest / #offline-expired 绑定门禁` → `#offline-transfer 文件传输页` → `#model-editor`
- **已知痛点**（AI推断·待确认）：链路依赖云端，**家庭断网 / 户外 / 弱网环境下打印机直接"变砖"**；且 APP 不提示当前网络状况，用户点下去才发现失败，无从判断是操作问题还是网络问题。
- **产品机会点**：把"打印机自带热点"这个硬件能力兑现成差异化体验——**断网也能打**；提醒条"不只报忧、并列给出路"；未绑定时明确说明原因 + 给「去绑定」引导，而不是让用户卡在传输页。
- **来源**：R002（§5 无网环境导入）
