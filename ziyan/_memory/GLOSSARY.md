# 术语与数据字段 (Glossary)

> ID 前缀 `GL-`｜**别名列是防"需求断开"的关键**：同一个东西在不同需求里换了名字，开发就会建两张表
> 发现别名必须立刻登记，后续需求一律使用标准术语

| ID | 标准术语 | 别名（禁用） | 定义 | 数据类型 | 来源 |
|----|---------|-------------|------|---------|------|
| GL-001 | 打印盘 | 盘、盘位、builder、plate、builder card | 分盘展示与打印的最小单元。一个模型可含多个打印盘，盘号从 1 起连续排列，**最大 8 盘** | int | 用户需求文档 §3.2 |
| GL-002 | 模型 | 部件、零件、model、part | 打印盘中可被编辑与打印的三维对象 | object | 用户需求文档 §4.2 |
| GL-003 | 模型编辑页 | 打印设置（详情页按钮文案）、Settings 页 | 本模块**主页面**。入口：模型详情页底栏「打印设置」按钮。含 3D 视图区、分盘切换、编辑工具栏、去打印 | 页面 | 用户需求文档 §2 |
| GL-004 | 打印设置页 | 更多页、参数页 | 模型编辑页顶栏「更多」进入的**打印参数页**。含打印模式/底座/温度/填充/支撑/保存 | 页面 | 用户需求文档 §2.2、§13 |
| GL-005 | 3D 视图区 | 模型视图区、3D 区域 | 模型编辑页中部显示打印空间（180×180×180 mm）与模型的区域 | 区域 | 用户需求文档 §4 |
| GL-006 | 自动摆盘 | 智能摆盘、重排 | 系统自动为当前打印盘重排模型位置，满足不越界、不碰撞、保留间距、提高利用率、减少位置变化 | 算法 | 用户需求文档 §10 |
| GL-007 | 云切片 | 切片、切片服务、云切片服务 | 由云端完成的模型校验→自动支撑→切片→路径计算→时间/耗材估算全流程 | 服务 | 用户需求文档 §12 |
| GL-008 | 打印模式 | 模式（快速/标准/精细） | 打印策略档位，单选，默认「标准」。底层层高/速度映射由切片策略配置，APP 不硬编码 | enum | 用户需求文档 §14 |
| GL-009 | 底座 | 平台附着、raft/brim | 模型与打印平台之间的附着结构，「带底座」为默认 | enum | 用户需求文档 §15 |
| GL-010 | 填充密度 | 填充、infill | 模型内部填充比例，默认 15%，单位 %，有效范围由服务端配置 | float(%) | 用户需求文档 §16 |
| GL-011 | 喷嘴温度 | 温度、nozzle temp | 喷嘴工作温度，默认 220°C，单位 °C，上下限按打印机型号/喷嘴/耗材动态配置 | int(°C) | 用户需求文档 §16 |
| GL-012 | 支撑 | 支撑结构 | 悬垂结构的辅助支撑。分「开启/关闭」开关 + 「树状支撑/线性支撑」类型 | object | 用户需求文档 §17–§19 |
| GL-013 | 去打印 | 开始打印、切片入口 | 模型编辑页主操作按钮，点击后提交云端切片 | 动作 | 用户需求文档 §12 |
| GL-014 | 准备打印页 | 准备打印 | 云切片成功后进入的页面，展示预计打印时间、耗材用量、盘数、打印机、参数摘要 | 页面 | 用户需求文档 §12.2 |
| GL-015 | 尺寸模式 / 百分比模式 | 缩放模式、mm 模式 / % 模式 | 缩放面板的两种输入方式：尺寸模式按 mm 输入 XYZ；百分比模式相对原始尺寸，范围 10%–300% | enum | 用户需求文档 §7.3–§7.4 |
| GL-016 | 等比例缩放 | 锁定比例、等比 | 缩放面板开关，默认开启；开启后改任一轴其余轴按原比例同步 | bool | 用户需求文档 §7.5 |
| GL-017 | 应用至所有盘 | 同步所有盘 | ⛔ 已更名 → 见 GL-024（作用范围同时被 DEC-021 修正，默认值改为**关闭**） | bool | 用户需求文档 §7.6 |
| GL-018 | 越界 | 超出打印区域、超界 | 模型任何部分超出 180×180×180 mm 打印空间。越界模型显示**红色**异常态，所在盘标记为异常盘 | 状态 | 用户需求文档 §11.2 |
| GL-019 | 异常盘 | 不可打印盘 | 存在越界或碰撞问题的打印盘。多盘中任意一盘异常 → 整个打印任务不可打印 | 状态 | 用户需求文档 §11.2 |
| GL-020 | 参数优先级 | 参数读取顺序 | 打印参数读取的 5 层顺序：任务内手动修改 > 模型已存参数 > 用户默认参数 > 系统默认 > 算法推荐。支撑参数特殊：未手改则允许算法重推 | 规则 | 用户需求文档 §23 |
| GL-021 | 电击小子_3D浮雕 | 演示模型、STL 模型 | R001 原型使用的真实演示模型（二进制 STL，79,916 三角面，实际尺寸 61.5 × 100.0 × 6.9 mm，X/Y 居中、Z 贴平台）。源文件：`ziyan/电击小子_3D浮雕.stl` | 资源 | 用户提供，2026-09-28 |
| GL-022 | 演示态 | 理想态、演示数据 | R001 原型内置的两套演示数据：**1 盘**（简单模型，支撑推荐"建议开启 + 树状支撑"）与 **8 盘**（复杂模型，含"无需支撑"的盘） | 资源 | R001 DEC-008 / DEC-014 |
| GL-023 | 零件 | 部件、子件 | **打印盘上的单个可打印对象**。复制/删除/选中/缩放的对象都是零件。⚠️ 用户需求文档原文将对象级对象写作「模型」，2026-09-28 起统一改称「零件」；「模型」仅指整个模型文件 | object | R001 DEC-019 |
| GL-024 | 应用至所有盘的零件 | 应用至所有盘（旧名） | 缩放面板开关，**默认关闭**，**单盘与多盘均展示**（DEC-023）。关闭 → **只缩放当前选中的那一个零件**；开启 → 全部打印盘上的零件按同一比例一起缩放（单盘时即该盘全部零件）。删除/复制始终只作用于选中的零件 | bool | R001 DEC-023 |
| GL-025 | 保存切片 | 保存 | 准备打印页底部左侧按钮。点击后经「命名 → 进度 → 成功」三步把本次切片存入「我的切片」 | action | R001 DEC-024 |
| GL-026 | 我的切片 | — | 用于查看已保存切片的页面/列表。**R001 判定"本期不实现"；R002 起正式落地**——作为导入选择弹窗的右侧菜单项，数据来源 =「我的」页面保存的切片记录（DEC-031）。展示方式与「我的 AI 创作」一致：两排多列网格 | page | R001 DEC-024 → R002 DEC-031 |
| GL-027 | 我的 AI 创作 | 我的模型（旧名，禁用） | 导入选择弹窗的左侧菜单项。数据来源 =「我的」页面中保存的 AI 创作记录，即用户上传/创作的模型。展示方式：**两排多列**网格 | list | R002 DEC-030 |
| GL-028 | 无网打印 | 离线打印、局域网打印、热点打印 | 无公网时经打印机热点局域网完成模型传输的模式。**仅支持 gcode、≤ 100MB**；进入传输页需 APP/设备**双向握手**通过（BR-057、DEC-028）；无网**不支持模型编辑**——目录确认按钮为「打印」，直传后返回来源页（BR-061、DEC-067） | 场景 | R002 §5 |
