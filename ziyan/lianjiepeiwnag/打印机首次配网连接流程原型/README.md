# 打印机首次配网连接流程 HTML 原型

双击 `index.html` 即可离线预览，无需安装依赖或启动服务。推荐使用 390 × 844 的移动端视口。

## 完整旅程

1. 起始页点击“添加打印机”。
2. 在打印机类型页处理“连接打印机前需要开启APP位置权限”提示，可取消或进入模拟手机设置；页面底部用纯白矩形盖住参考图中的“暂不设置”。
3. 选择 Ugee Funbox，进入合并后的打印机准备页。
4. 完成连接电源与配网准备后，进入打印机热点连接引导。
5. 点击底部唯一的“前往设置 WLAN”按钮，进入模拟系统 WLAN 页（默认连接 `Home_5G`）。
6. 选择 `Ugee Funbox-AP` 后点击左上角“‹ Ugee”返回，直接跳转到“网络配置”页。
7. 未选择 `Ugee Funbox-AP`（保持 `Home_5G` 或改选其他网络）返回，则回到连接打印机热点页，并弹出“你还没有连接到打印机WiFi，请返回设置连接打印机WiFi热点”提示。
8. 在“网络配置”页选择 `Home_5G`、输入演示密码 `12345678` 并点击“连接”。
9. 等待 3 秒后显示连接成功提示，并自动进入“打印前准备”。

- 起始页和打印机类型页直接复用项目参考图，并增加可点击热区；打印机类型页底部叠加与截图底部同色的纯白矩形（`.reference-cover`），盖住参考图中的“暂不设置”文字与底部横条。

- 从打印机准备页起至打印前准备终页统一采用蓝紫主题：主操作为蓝紫色，步骤条、视频演示、加载与状态反馈使用同一色系。
- 热点连接页使用视频占位符与 `../../src/lianjiepeiwnag/WiFi设置示意图.jpg` 热点示例图；底部只保留全宽的“前往设置 WLAN”按钮，已删除“下一步”，返回提示同步改为“设置好后返回，将自动进入网络配置”。

## 统一关闭确认交互（可复用组件）

除终页「打印前准备」外，所有页面右上角的关闭图标点击后都先弹二次确认，避免用户误触中断配网。

**受影响页面清单（`data-close="confirm"`，共 3 页）**

| 页面 | `data-screen` | 标题 |
| --- | --- | --- |
| 打印机准备 | `printer-ready` | 打印机准备 |
| 连接打印机热点 | `hotspot` | 连接打印机热点 |
| 网络配置 | `home-wifi` | 网络配置 |

**不弹确认的一页**：`print-ready`「打印前准备」标为 `data-close="direct"`，保持原有直接回到起始页的行为。

**交互规则**

1. 弹窗文案固定为「打印前，请务必完成打印机设置，只需几分钟即可完成」，标题「温馨提示」。
2. 弹窗含「取消」「确认」两个按钮，沿用既有 `.app-dialog` / `.dialog-icon` / `.dialog-actions` 样式规范；取消为常规文字按钮，确认为蓝紫主操作。
3. 点「取消」（或按 Esc、点遮罩）：关闭弹窗并**停留在当前页面**，页面状态与已填写数据（WiFi 选择、WiFi 密码等）完全不变，焦点回到刚才的关闭图标。
4. 点「确认」：关闭弹窗，复位流程内状态（计时器 / 弹层 / WiFi 选择 / 密码）并跳转回工作台页面 `../../dayinji/自研款打印机打印页面原型/index.html`。
5. 连点关闭图标只会弹出一个弹窗，不会叠加。

**组件调用方式与参数设计**

组件为 `prototype.js` 里的工厂函数 `createConfirmDialog(options)`，运行时用 `createElement` 拼装并挂到 `body`，因此可以创建多个互不干扰的实例：

```js
// 1) 建实例（全部参数可选，均有默认值）
const askExit = createConfirmDialog({
  message: '打印前，请务必完成打印机设置，只需几分钟即可完成',
  confirmText: '确认',
  cancelText: '取消'
});

// 2) 调用：ask() 返回 Promise<boolean>，true = 确认，false = 取消
closeButton.addEventListener('click', async (event) => {
  if (await askExit.ask(event)) {
    // 只有确认分支才改动页面状态；取消时这里什么都不执行
  }
});
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `message` | string | `''` | 正文文案；留空则不渲染 `<p>`，避免多余行间距 |
| `title` | string | `'温馨提示'` | 标题文案 |
| `icon` | string | `'!'` | 标题上方图标字符 |
| `iconClass` | string | `'dialog-icon--notice'` | 图标配色修饰类（蓝紫 / 蓝色） |
| `confirmText` | string | `'确认'` | 主操作按钮文案 |
| `cancelText` | string | `'取消'` | 次操作按钮文案 |
| `dismissible` | boolean | `true` | 按 Esc / 点遮罩是否等同「取消」 |

返回值 `{ element, ask }`：`element` 是生成的 `<dialog>`（便于测试或高级控制），`ask(event)` 返回 `Promise<boolean>`。

**设计要点**

- `ask()` 传入事件时用 `event.currentTarget` 记录触发按钮，取消后把焦点还回去，保证键盘可达性。
- 展示中重复调用 `ask()` 会复用同一个 Promise，不会叠出多个弹窗。
- Esc / 点遮罩在 `dismissible: true` 时统一走「取消」分支（`preventDefault` 后手动结算），不会误触发确认。
- 关闭图标的分流靠 HTML 上的 `data-close` 值决定，JS 只有一处监听，新增页面只需标对属性，不必再写逻辑：

```html
<button type="button" data-close="confirm" aria-label="退出配网流程">×</button>  <!-- 弹确认 -->
<button type="button" data-close="direct"  aria-label="退出配网流程">×</button>  <!-- 直接退出 -->
```

## 「帮助」→ 连接配网常见问题解决方案弹窗

对应需求文档 2.2 连接配网 · 步骤 1「点击添加打印机」逻辑第 4 点：点击帮助按钮弹出常见问题解决方案弹窗，并给出连接配网 FAQ 网址跳转链接。

**入口**：起始页（添加打印机页）右上角「帮助」。起始页是整图复用页，「帮助」二字已烘焙在 `起始页.png` 上（686 × 1530 原图内 x 605~659 / y 131~157），因此用 `.hotspot-help` 叠一层透明按钮把可点区域放大到 51 × 45px（≥44px）。v1 与儿童受限账号 v2 两个起始页共用同一张整图，接线到同一个弹层（`#start-help` / `#start-help-v2`）。

**弹层**（`#faq-dialog`，`.sheet` 通用外壳）

1. 自下而上滑入（`sheet-up` 280ms），贴底弹出，顶部有拖拽条与右上角关闭按钮。
2. 标题「连接配网常见问题」，正文为 5 条常见问题 + 解决方案（搜索不到打印机 / 连不上打印机热点 / 家庭 WiFi 配网失败 / 配网成功但离线 / 长按无反应），每条用问号圆形图标 + 加粗问题 + 灰度方案正文。
3. 底部文案 `【详情查看连接配网常见问题】`，其中「连接配网常见问题」是 `<a class="faq-more__link">`——蓝色（`var(--blue)` #5B68EF）带下划线，可点击 / 可键盘聚焦（`tabindex="0"`，Enter 与 Space 均响应）。
4. 点击后**模拟跳转至外部网址**：原型阶段只弹 Toast「正在跳转至官方连接配网FAQ页面（原型不离开当前页）」，不真的离开当前页，避免评审时跳出原型。真实实现走系统浏览器 / 内嵌 WebView 打开 `FAQ_URL`，需要真跳转时取消 `prototype.js` 里 `goToFaqLink()` 的注释即可。
5. 点遮罩、点关闭按钮、按 Esc 均可关闭，焦点回到刚才的「帮助」按钮。

## 【连接等待】页

对应需求文档 2.2 连接配网 · 步骤 5「为打印机配置家庭 WiFi」逻辑第 2 点。

**进入**：网络配置页输入密码点「连接」→ 自下而上弹出 `#connecting-dialog`（`.sheet` 外壳 + 蓝色圆圈主体）。

**页面构成**

| 元素 | 说明 |
| --- | --- |
| 蓝色填充圆圈 `.connecting-core` | 124 × 124px 正圆，`background: var(--brand)`（#675BE6），圆心为文案**【正在连接打印机中...】**（白色 14px，与圆圈严格同心） |
| 「动态点击」动效 `core-tap` | 1.2s 无限循环的按下-回弹脉冲（1 → .9 → 1.03 → .97 → 1），模拟正在连接的动态点击感 |
| 水波纹虚线圆圈 `.ripple--1/2/3` | 三圈浅蓝色（#A9CDFB）**虚线**圆环，132 / 168 / 204px，`ripple-out` 2.4s 依次向外扩散并淡出（延迟 0 / .8 / 1.6s） |
| 副文案 | 「请保持手机靠近打印机，不要退出应用」 |
| 计时 | 「已等待 N 秒，连接超过 60s 将提示失败」，1s 一跳；真实阈值 `CONNECTING_TIMEOUT_SECONDS = 60` |
| 演示控件 | 「模拟连接成功」/「模拟 60s 超时」两个按钮 + 演示角标，代替真实网络请求，让两条分支当场可复现（不用真等 60s） |

**正常分支**：连接成功 → 关闭本页 → 显示「连接成功」提示（复用 `连接成功.jpg`）→ 约 0.9s 后进入【打印前准备】。

**异常分支（60s 超时）**：关闭本页 → 回到【网络配置】页 → 弹出提醒弹窗，文案 `连接失败，请检查：1.WiFi密码是否正确；2.在点击连接前手机是否连接上打印机WiFi热点`（按需求文档原文，此处用「，」；上方**即时校验**的密码错误提示沿用既有的 `连接失败：…`「：」，两者是不同场景、不改既有文案）→ 只有【确定】一个按钮 → 点确定后回到【网络配置】页，**密码输入框内容自动清空**并恢复掩码态、移除 `aria-invalid`、焦点落在密码框，用户重新输入即可再次发起连接（异常可恢复）。

> `showNotice()` 新增第三个可选参数 `onConfirm`，用于在弹窗关闭后执行额外动作（此处即清空密码框）。`resetPairingFlowState()` 退出流程时一并清理【连接等待】页计时器与常见问题弹层。

## 发布

两个原型之间是用 `../../` 相对路径互跳的：

- 本流程终页左上角回退 → `../../dayinji/自研款打印机打印页面原型/index.html`
- 本流程终页「去进料」→ `../../dayinji/自研款打印机打印页面原型/index.html?highlight=filament`
- 本流程终页「去打印」→ `../../dayinji/自研款打印机打印页面原型/index.html?screen=explore-toys`
- 打印页面原型「添加打印机 → 配置新的打印机」→ 本流程 `index.html?screen=printer-select`
- 儿童受限账号「家长授权 → 加入共享打印机 → 查看我的打印机」→ 打印页面原型

所以**必须两个原型发布在同一个站点里**，并保持 `lianjiepeiwnag/…`、`dayinji/…`、`src/`、`原型修改复用图片资源/`、`ugee/` 的相对目录结构不变；分开发布成两个站点会让跨原型跳转 404。

```powershell
python tests\build-publish.py                 # 生成 ziyan/_publish-prototypes（只复制被引用到的资源，约 14 MB，自带发布根页）
python tests\build-publish.py <输出目录>       # 可选：指定其他输出目录（如另起新发布链接时保留原目录不动）
node tests\publish-links-check.mjs <站点根URL> # 校验互通：两个原型首页、双向跳转、儿童 v1/v2 链路与深链，共 40 项断言
```

发布根页会自动列出两套原型的入口（起始页 / 演示台 / 儿童受限账号 / 儿童受限账号v2 / 加入共享打印机 / 分享打印机），直接把根链接发给评审即可。
