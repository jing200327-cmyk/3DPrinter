2 主线 A · 编辑并打印（理想路径） 编辑操作 → 自动摆盘 → 可打印性校验 → 云切片 → 准备打印 → 保存切片
自动摆盘智能优化
进入编辑页前由系统自动完成：多文件模型在不超过打印空间的前提下，同色模型文件合摆至同一盘，压缩盘数（示例 10 个文件 → 5 盘）
无手动入口 · 仅 Toast 告知结果
选中零件
点击零件进入选中态（橙色包围框），点空白取消。同一时间仅允许选中一个零件
未选中点按钮 → Toast
缩放
面板：尺寸(mm) / 百分比(10–300%)、等比例、应用至所有盘的零件。实时生效，无需确定
默认只缩放选中的零件
复制
副本继承尺寸 / 缩放比例 / 方向，默认进入选中态；优先在当前盘摆放
空间不足则不新建盘
删除
常规删除不弹确认；删任务最后一个零件时二次确认，确认后任务自动移除、不可恢复。该盘无零件则回收空盘、盘号前移
取消 → 留在编辑页
自动摆盘
缩放结束 / 复制 / 删除后触发，仅作用于当前盘。不越界、不碰撞、保留间距、尽量减少位置变化
静默完成，无动画
可打印性校验
6 个时机触发：首次加载 / 切换盘 / 缩放 / 复制 / 删除 / 摆盘完成
越界 / 碰撞 → 红态
去打印
5 个条件同时满足才可点，否则置灰并在按钮上方显示阻断原因
Loading 期禁止重复提交
云切片
云端依次完成：合法性校验 → 自动支撑 → 切片 → 路径计算 → 时间估算 → 耗材估算

主线 B · 多盘任务的编辑 盘号从 1 连续编号，上限 8 盘
盘号切换
默认选中第 1 盘；宽度不足时盘号区横向滑动。切盘 → 3D 视图只显示该盘零件、清空选中、关闭缩放面板
应用至所有盘的零件
默认关闭，单盘/多盘均展示。关闭时只缩放选中的零件；开启后全部打印盘的零件一起缩放（单盘即该盘全部零件）
空盘回收
某盘最后一个零件被删 → 该空盘自动删除、后续盘号前移重编号、切到最近有效盘
8 盘上限
盘号区可横向滑动
无零件 → 去打印置灰
保留唯一空盘
打印参数默认作用于整个任务
打印模式 / 底座 / 喷嘴温度 / 填充密度对所有打印盘统一生效；用户指定的支撑开关与类型作为整个任务的统一策略。本期不支持每盘独立参数
主线 C · 参数调整与持久化 修改即时生效，保存决定持久化
打印参数（6 项）
打印模式（快速 / 标准 / 精细）、底座（带 / 不带）、喷嘴温度、填充密度、支撑开关、支撑类型
支撑由算法推荐
首次进入由切片算法分析模型给出推荐并提示「已根据模型自动推荐」；用户手动改过后以用户设置为准，不再自动覆盖
恢复默认值
二次确认后 6 项复位；支撑参数重新执行一次模型自动分析，恢复为算法推荐值
保存范围
仅用于当前模型 / 后续模型默认使用 / 取消
关闭支撑
类型区置灰但保留上次选择
① 保存范围弹窗
未选范围 → 底部「取消」
② 选中后 → 「确定」
确定 = 保存并返回编辑页
参数读取优先级（5 层）
① 当前任务手动修改值 → ② 当前模型已保存参数 → ③ 用户默认参数 → ④ 系统默认参数 → ⑤ 算法自动推荐。支撑参数特殊：用户未手改时允许算法按当前模型重新推荐
4 异常与边界 所有失败都给具体原因与下一步动作，绝不静默
零件越界 / 重叠
红色异常态 + 该盘标记异常；任一盘异常则整个任务不可打印
复制空间不足
不自动新建打印盘，复制失败并提示「当前打印盘空间不足，无法复制」
删除最后一个零件
二次确认「任务将自动被移除且不可恢复」；取消则返回编辑页
网络 / 服务异常
网络异常请检查网络后重试；切片服务暂不可用请稍后重试
模型解析失败
模型文件异常，暂无法打印
未选中零件
三个编辑按钮不置灰，点击提示「请先选择一个零件」
