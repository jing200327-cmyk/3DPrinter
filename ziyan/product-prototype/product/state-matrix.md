# 3D 打印机连接与配网：State Matrix

## 约定

- 原型默认使用 mock 设备和网络数据，不依赖真实蓝牙、定位或 WiFi API。
- “重试”应保留已完成的上游步骤；除非用户主动返回入口，不要求重新选择连接方式。
- 系统设置页是外部状态：原型以“前往设置”和“返回 App 后检查”模拟，不伪造系统设置成功。

| 流程 | 状态 | 触发条件 | 用户可执行动作 | 下一状态 / 处理 |
| --- | --- | --- | --- | --- |
| 蓝牙 | 等待权限 | 首次进入搜索附近设备 | 允许、拒绝、关闭 | 允许后检查蓝牙；拒绝进入权限受限 |
| 蓝牙 | 权限受限 | 蓝牙或位置权限被拒绝/关闭 | 再次授权、前往设置、返回 | 权限恢复后进入搜索；否则保留说明 |
| 蓝牙 | 搜索中 | 蓝牙与位置权限均可用 | 刷新、取消、选择设备 | 有结果进入设备列表；超时进入无设备 |
| 蓝牙 | 无附近设备 | 搜索超时或无结果 | 重试、检查设备、返回 | 重试回到搜索中 |
| 蓝牙 | 设备列表 | 找到一个或多个设备 | 选择 `Ugee Ufun`、刷新 | 选择后进入自动绑定 |
| 蓝牙 | 自动绑定中 | 已选择设备 | 等待、取消 | 成功显示绑定提示；失败进入绑定失败 |
| 蓝牙 | 自动绑定提示 | 设备已绑定 | 继续 | 进入连接网络 / WiFi 搜索 |
| 蓝牙 | WiFi 搜索中 | 已完成设备绑定 | 刷新、返回 | 有结果进入 WiFi 列表；超时进入无 WiFi |
| 蓝牙 | 无 WiFi | 搜索超时或无结果 | 重试、返回 | 重试回到 WiFi 搜索中 |
| 蓝牙 | WiFi 密码输入 | 已选择家庭 WiFi | 输入、显示/隐藏密码、连接、取消 | 合法提交进入连接中；取消回 WiFi 列表 |
| 蓝牙 | 连接中 | 已提交 WiFi 凭据 | 等待、取消 | 成功进入连接成功；失败进入配网失败 |
| 蓝牙 | 配网失败 | 密码错误、网络不可用、超时或设备断开 | 重试、修改网络/密码、返回 | 保留 WiFi 上下文；可回密码输入或 WiFi 列表 |
| 蓝牙 | 连接成功 | 设备已接入网络 | 完成 | 退出流程或进入打印机详情（后续定义） |
| WiFi | 等待位置权限 | 首次进入型号选择 | 允许、拒绝、关闭 | 允许后展示型号；拒绝进入权限受限 |
| WiFi | 型号选择 | 位置权限可用 | 选择型号、返回 | 选择后进入配网准备 |
| WiFi | 配网准备 | 已选择型号 | 前往 WLAN 设置、下一步、返回 | 前往外部系统设置；未完成热点连接时阻止下一步 |
| WiFi | 系统 WLAN 设置 | 用户跳转至系统设置 | 连接 `Ugee Funbox-AP`、返回 App | 返回后进入热点连接校验 |
| WiFi | 热点检测中 | App 恢复前台 | 等待、返回设置 | 已连接进入家庭 WiFi；未连接进入热点未连接 |
| WiFi | 热点未连接 | 未检测到 `Ugee Funbox-AP` | 返回设置、再次检测、返回 | 再次检测回热点检测中 |
| WiFi | 家庭 WiFi / 密码 | 已连接打印机热点 | 选择家庭 WiFi、输入密码、连接、取消 | 提交后进入配网中 |
| WiFi | 配网中 / 自动绑定 | 已提交家庭 WiFi 凭据 | 等待、取消 | 成功进入连接成功；失败进入配网失败 |
| WiFi | 配网失败 | 密码错误、热点断开、超时或设备无响应 | 重试、修改网络/密码、重新连接热点 | 根据失败原因回到家庭 WiFi 或热点校验 |
| WiFi | 连接成功 | 家庭 WiFi 配置与绑定完成 | 完成 | 退出流程或进入打印机详情（后续定义） |

## 边界情况与原型处理

| 场景 | 处理原则 | 原型应体现 |
| --- | --- | --- |
| 蓝牙权限拒绝、位置权限拒绝或系统开关关闭 | 不开始搜索；说明所需能力和恢复路径 | 权限受限状态、再次授权/前往设置/返回 |
| 搜索不到蓝牙设备 | 不结束流程；让用户确认设备状态后重试 | 空状态、刷新、返回 |
| 搜索到多个设备或同名设备 | 原型需允许列表选择；真实设备识别规则待产品确认 | 设备列表，`Ugee Ufun` 作为 mock 目标 |
| 选择设备后自动绑定失败 | 保留已选设备，提供重试与更换设备 | 绑定失败状态 |
| 附近 WiFi 列表为空或刷新失败 | 不丢失蓝牙绑定；允许刷新或返回 | WiFi 空状态、刷新 |
| WiFi 密码为空、格式不合法或错误 | 提交前校验；失败后保留 SSID，允许改密重试 | 输入校验、密码错误状态 |
| 配网等待超时、打印机断开或家庭网络不可用 | 明确失败原因；从最小必要步骤恢复 | 配网失败、重试、修改网络或重新连接热点 |
| WiFi 路径未连接 `Ugee Funbox-AP` 就返回 App | 阻止进入下一步，指向系统 WLAN 设置 | “尚未连接打印机 WiFi”提示、返回设置 |
| 用户从系统设置返回但 App 未立即获得状态 | 显示检测中，支持再次检测 | 热点检测中/失败状态 |
| 用户在流程中返回、取消或切换连接方式 | 不产生半完成的成功状态；已绑定与否须明确 | 返回确认或安全退出；切换后回连接方式入口 |
| App 进入后台、权限在流程中被收回 | 恢复前台时重新检查必需状态 | 恢复校验；缺失能力时回权限受限 |

## 待人工确认的产品决策

1. 蓝牙发现多个同名设备时的识别信息（序列号、信号强度或设备码）。
2. 家庭 WiFi 的频段与加密方式支持范围，以及对应的提示文案。
3. 连接成功后是否进入打印机详情页，还是返回设备列表。
4. 自动绑定失败、热点连接失败和配网失败的最终错误码/文案规则。
