# 产品决策记录

## 2026-09-08｜蓝牙绑定后直达家庭 Wi-Fi 列表

- 状态：已确认（人工修改为准）
- 决策：跳过中间网络连接页，直接从 `B-01 / Device search / Device discovered` 页面连接到 `B-03 / Home Wi-Fi list`。
- 原因：减少页面步骤，降低用户使用难度。
- 副产物：自动绑定成功提示被删除并非有意。
- 后续修改方向：在 `B-03 / Home Wi-Fi list` 页面首次进入时，显示一个“已绑定成功”的低干扰提示；提示持续 1 秒后渐隐。它应尽可能小，不妨碍用户继续配置网络；即使用户未注意到该提示，也不影响后续操作。
