# 3D 打印机连接与配网：核心 User Flow

## 范围与前提

- 目标：在手机 App 中完成手机与 3D 打印机的绑定与家庭 WiFi 配网。
- 连接入口：已有“添加打印机”和“选择连接方式”页面，本轮不改造它们。
- 方式：蓝牙连接、WiFi 连接。
- 原型使用 mock 数据；示例打印机为 `Ugee Ufun`，示例打印机热点为 `Ugee Funbox-AP`。
- 本文定义行为、跳转和状态，不定义视觉 UI。

## 蓝牙连接主流程

```text
添加打印机（已有）
  → 选择连接方式（已有）
  → 选择“蓝牙连接”
  → 搜索附近设备页：先请求蓝牙与位置权限
  → 权限已允许后开始搜索
  → 找到并选择 “Ugee Ufun”
  → 自动绑定成功提示
  → 连接网络页：搜索附近 WiFi
  → 选择家庭 WiFi
  → 输入密码并确认连接
  → 配网中 / 等待连接
  → 连接成功
```

### 蓝牙流程的交互规则

1. 进入“搜索附近设备”页后，若蓝牙或位置权限未授予，立即显示权限弹窗；用户可允许、拒绝或关闭弹窗。
2. 仅当蓝牙和位置权限均可用时进入搜索状态。搜索状态应可刷新、可取消，且支持超时结果。
3. 搜索结果出现 `Ugee Ufun` 后，用户点击该设备进入绑定。绑定完成后先显示“已自动绑定”提示，再进入“连接网络”。
4. “连接网络”是第二步：持续/刷新搜索附近 WiFi；选择 WiFi 后打开密码输入状态。
5. 密码提交成功后进入“正在连接”；连接成功后进入完成页。失败时保留当前 WiFi 与重试入口，避免用户从头开始。

## WiFi 连接主流程

```text
添加打印机（已有）
  → 选择连接方式（已有）
  → 选择“WiFi 连接”
  → 选择打印机型号（复用现有原型；先请求位置权限）
  → 配网准备（复用）
  → 引导前往系统 WLAN 设置
  → 连接打印机热点 “Ugee Funbox-AP”
  → 返回 App 并校验热点连接
  → 选择家庭 WiFi
  → 输入密码并确认连接
  → 配网中 / 自动绑定
  → 连接成功
```

## 进度语义

- 蓝牙路径固定为两步：`1 搜索附近设备` → `2 连接网络`。
- 自动绑定是设备选中后的系统动作，不单列为用户手动步骤。
- WiFi 路径的既有进度语义以复用原型为准；新入口不改变原有步骤编号。

## 原型验收路径

1. 从“添加打印机”进入连接方式选择。
2. 蓝牙路径完整演示：权限 → 搜索 → `Ugee Ufun` → 自动绑定提示 → WiFi → 密码 → 连接成功。
3. WiFi 路径完整演示：位置权限 → 型号 → 准备 → WLAN 设置/返回校验 → 家庭 WiFi → 密码 → 连接成功。
4. 每个失败状态都可重试、返回上一步或退出；不应形成无出口状态。
