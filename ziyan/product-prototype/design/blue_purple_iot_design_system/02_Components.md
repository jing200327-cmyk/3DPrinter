# Components

## GradientButton

Purpose: 主要用户流程跳转按钮。

Variants: - primary

States: - default - pressed - loading - disabled

Usage: - Connect Printer - Continue - Start Setup - Finish

## BlueModal

Purpose: 设备连接提示弹窗。

包含: - icon - title - description - primary action - secondary action

## Input

用途: WiFi密码。

## Select

用途: 网络选择。

## Card

用途: 设备信息、WiFi信息展示。

## StatusBadge

用途: 显示: - Connecting - Connected - Failed
