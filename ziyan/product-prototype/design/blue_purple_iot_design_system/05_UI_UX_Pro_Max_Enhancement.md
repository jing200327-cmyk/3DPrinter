# UI UX Pro Max Enhancement Guide

## Role

UI UX Pro Max 作为视觉增强层。

不改变: - Token - Component - Brand Color - Interaction Flow

## Enhance

### Visual Hierarchy

优化: - Typography - Spacing - Content grouping

### IoT Experience

增加: - Device illustration - Connection progress - Signal indicators -
Micro animation

### Empty State

增加: - Friendly illustration - Helpful explanation - Clear CTA

### Loading

不要使用简单 Loading。

推荐:

Searching printer \| WiFi connected \| Device verified \| Ready
