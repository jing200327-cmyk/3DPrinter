# AI Generation Rules

## MUST

1.  使用已有 Token。
2.  使用已有 Component。
3.  Primary Action 使用蓝紫渐变。
4.  状态反馈使用蓝色主题。
5.  页面必须体现连接流程。
6.  优先移动端布局。

## MUST NOT

1.  不创建随机颜色。
2.  不创建新的按钮样式。
3.  不使用桌面后台 UI。
4.  不使用黑色主按钮。

## New Component Request

必须包含:

-   Name
-   Purpose
-   Variants
-   States
-   Tokens
-   Accessibility
