# Blue Purple IoT AI Design Resource System

## Purpose

This resource system extends the Design System Foundation into an
AI-callable product design library.

It provides:

-   Components
-   Mock Data
-   User Flows
-   Page Templates
-   AI Prompt Rules

Target:

Mobile IoT Printer Connection and Network Setup Experience.

## Resource Layers

Tokens: Define visual language.

Components: Define reusable UI building blocks.

Mocks: Provide realistic product data.

Flows: Define user journey and state transitions.

Pages: Define reusable screen structures.

Prompts: Define how AI uses resources.
