# 自研款打印机打印旅程 HTML 原型

双击 `index.html` 即可离线预览，无需安装依赖或启动服务。推荐使用 390 × 844 的移动端视口。

## 完整旅程

1. 从复用 `模型详情页.jpg` 的起始页点击“立即打印”；透明热区已向右上调整，准确覆盖原图按钮。
2. 在准备打印页横向浏览并单选 3 个 185 × 258 px 盘卡；盘 2 使用 `选择要打印的盘2（修改）.jpg`，列表支持真实点击切盘、触控滑动和鼠标拖动，拖动后仍可继续选择其他盘，所选盘同步成为耗材匹配区的模型预览。
3. 点击“预览”提示“已打开预览”；在 CFS lite 与外挂料盘之间单选耗材来源。
4. CFS lite 模式下打开仓内耗材选择页，可选 1、2、4 号仓，3 号空仓不可选；紧凑单选热区覆盖原图圆点位置，确认后回填仓号、颜色和 PLA 类型。
5. 使用覆盖原图加减号的透明热区调整 1–9 份打印份数，独立选择打印校准和延时摄影。
6. 点击“开始打印”显示真实 2 秒上传进度，然后携带所选盘位和 `status=preparing` 跳转至自研款打印机打印页面原型；新任务先进入 30 秒准备中，再自动切换打印中，任务图、参数和剩余队列图片均由所选盘位决定。

## 队列返回状态

- 打印中从打印队列进入设置页：页面顶部显示红色“打印机正在打印”，点击开始打印时的盘显示黑底蓝字梯形“正在打印”标签；继续浏览其他盘不会移动该标签。
- 打印完成后从打印队列进入设置页：上次选择的盘显示黑底白字梯形“已打印”标签。
- 两种状态均通过 URL 参数传递盘位和任务状态；从已打印设置页返回时继续保持打印完成态。

## 文件

- `index.html`：模型详情与准备打印页面结构
- `styles.css`：参考图布局、横向盘位、仓内耗材、上传弹窗与状态标签样式
- `prototype.js`：盘位、耗材、份数、选项、上传和跨原型状态交互
- `prototype-settings.png`：准备打印设置验收图
- `prototype-filament-picker.png`：仓内耗材小型单选覆盖验收图
- `prototype-uploading.png`：上传中进度验收图
- `prototype-printing-status.png`：正在打印标签验收图
- `prototype-completed-status.png`：已打印标签验收图
- `tests/prototype-contract.ps1`：需求结构契约测试
- `tests/browser-e2e.mjs`：隔离式 Chrome 跨原型全旅程测试
