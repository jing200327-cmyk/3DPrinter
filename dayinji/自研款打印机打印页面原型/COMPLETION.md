# 打印完成庆祝页

入口：`index.html?status=completed`；工作台任务从打印中进入完成状态时也会自动出现。

- 0–0.3 秒：完成标题淡入、成功对勾。
- 0.3–1.2 秒：分层星星、彩色纸屑及底部光圈爆发，向外扩散。
- 1.2–2.2 秒：奖励卡弹入、创作积分从 0 增长至 10。
- 2.2 秒后：爆发粒子清空，只保留少量漂浮星星及缓慢旋转的模型。
- 点击作品再次召唤星星，拖动旋转；“看看我的作品”进入作品展示状态。
- “再创造一个”接回现有探索玩具模型选择页；“我知道了”及 Escape 关闭庆祝页，保留工作台打印完成状态。
- 支持系统减少动态效果偏好及页面减弱动画开关。奖励积分为本次原型演示，不写入真实账户。

作品为与当前默认史蒂夫任务对应的程序化 3D 展示示意，使用项目已有的本地 Three.js。真实设备集成时需替换成当前任务的切片模型；安全提示始终保留，不根据演示动画推断实际冷却状态。

验证：Chrome 无头浏览器覆盖自动弹出、奖励数字、粒子清理、减弱动画、作品展示、关闭返回、模型选择和多个屏幕尺寸。
